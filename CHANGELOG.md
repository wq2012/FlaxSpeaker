# Changelog

## 0.5.0

Clean `v0.5.0` architecture refactor, 48-model two-tier pretrained zoo (`44` controlled ablation models + `4` full-data `12,193`-speaker universal flagships), 16-candidate `PFAS` sweep, 2-way/3-way heterogeneous score fusion, and 16 FP32/INT8 TFLite exports.

### Engine & Architecture Updates
- **Unified `ExperimentConfig` + `ModernSpeakerEncoder` API**: removed legacy `munch` configuration shims, legacy `LstmSpeakerEncoder` / `TransformerSpeakerEncoder` modules, and legacy triplet-only loops across `flaxspeaker/configs.py`, `flaxspeaker/neural_net.py`, and `flaxspeaker/evaluation.py`.
- **Polite shared-machine resource caps (`flaxspeaker/resources.py`)**: added `configure_polite_resources` to cap thread pools (`OMP_NUM_THREADS`, `MKL_NUM_THREADS`, `OPENBLAS_NUM_THREADS`, `XLA_FLAGS` `intra_op_parallelism_threads`), `os.nice`, and `os.sched_setaffinity`.
- **`BatchNorm` running-statistics ECAPA-TDNN & `Large` backbone presets**: added mask-aware `nn.BatchNorm` running statistics (`SpeakerTrainState.batch_stats`, `.safetensors` `batch_stats.*` serialization, and `jax2tf` / TFLite export support) as the `v0.5.0` default for `EcapaTdnnBackbone` (`use_batch_norm=True, norm_after_activation=True`), plus `ModelSize.LARGE` presets for `Conformer-Large` (`dim=384, num_layers=6, num_heads=6, ffn_dim=1536, subsample_factor=4`, `6.98M–7.31M` params) and `ECAPA-TDNN-Large` (`channels=1024, scale=8, mfa_dim=1536, se_bottleneck_dim=128`, `14.92M` params).
- **Sub-Center `ArcFace` (`K=3`), `SGD + Nesterov`, warm-start & Two-Stage `LMFT`**: added `LossType.SUBCENTER_ARCFACE` (`subcenter_arcface_loss`), `SGD + Nesterov` with additive weight decay, pretrained trunk warm-starting (`warm_start_train_state`, `freeze_trunk`, `trunk_lr_mult`) for `PFAS` and `Dr-Vectors` heads, and Two-Stage Large-Margin Fine-Tuning (`build_lmft_config`, `run_lmft`).
- **Real waveform augmentation & `float16` memory-mapped shard pipeline (`flaxspeaker/waveform_aug.py`, `flaxspeaker/sharded_cache.py`)**: added `MusanRirAugmenter` (`MUSAN` noise/music/babble + `RIRS_NOISES` FFT reverb), `3x` polyphase speed perturbation (`0.9x`, `1.0x`, `1.1x`), WebDataset `.tar` streaming (`ffmpeg` pipe decode), and zero-copy `np.memmap` `float16` feature shards (`ShardedFeatureWriter`, `ShardedFeatureDataset`).
- **Full-utterance inference, Top-300 `AS-Norm`, `QMF` calibration & official benchmark loaders**: made unclipped full-utterance bucketed inference (`max_eval_seq_len=0`, capped at `3000` frames) the clean default, wired vectorized Top-300 `AS-Norm` (reporting both `raw` and `as_norm` metrics) and logistic Quality-Aware Score Calibration (`QMF`), expanded `PFAS` hyperparameter support, and added official benchmark loaders/evaluators for 40-speaker `VoxCeleb1-O`, 200-speaker `CN-Celeb-E`, and 40-speaker `LibriSpeech test-clean`.

## 0.4.0

Full-convergence 44-checkpoint model zoo release (`S_safe = X + 2 epochs`), linear angular-margin warm-up (`margin_warmup_steps`), uniform variable-length masked training (`variable_length_training: true`) across all 44 models, re-exported FP32/INT8 TFLite models, and converged R1/R2 ablations and controls.

### Library & Training Features
- **Angular-margin warm-up (`LossConfig.margin_warmup_steps`)**: `make_modern_train_step` in `flaxspeaker/neural_net.py` supports linear margin warm-up over the first `margin_warmup_steps` updates for additive angular-margin classifiers (`arcface` and `cosface`: $m_{\text{eff}}(t) = m \cdot \min(1, t / T_w)$) and multiplicative `sphereface` ($m_{\text{eff}}(t) = 1 + (m_s - 1) \cdot \min(1, t / T_w)$), stabilizing early angular-margin optimization without initial gradient collapse (`tests.py::test_angular_margin_warmup_steps`).
- **Scaled dot-product PFAS attention (`attention_type="dot"`) & validation**: `PfasRepresentationHead` in `flaxspeaker/pooling.py` adds a scaled dot-product query-key mode alongside `"mlp"`, `"atp_ffn"`, `"shared_nonlinear"`, and `"maxpool"`, and raises `ValueError` on unknown `attention_type`.
- **Clean YAML serialization of `StrEnum` fields**: `flaxspeaker/configs.py` registers a `yaml.SafeDumper` multi-representer for `_StrEnum` subclasses so `ExperimentConfig.to_yaml()` emits plain YAML scalars cleanly across Python 3.10–3.12+.

### Full-Convergence 44-Model Zoo (`S_safe = X + 2 epochs`)
- **Phase-1 5,000-step convergence calibration** (`scripts/run_phase1_convergence_pilot.py` → `pretrained_models/phase1_convergence_pilot.json`): calibrated dataset- and family-specific convergence plateaus $X$ across 12 representative pilot runs up to 5,000 steps, setting every production schedule to $S_{\text{safe}} = X + 2\text{ epochs}$ with 10% linear LR warm-up and cosine decay:
  - **Universal** (19 models; 9,447 utts / 381 spks): **4,600 steps** (15.58 epochs; `margin_warmup_steps=500` on `univ_conformer_small_arcface` and `univ_conformer_small_cosface`).
  - **LibriSpeech** (19 models; 5,788 utts / 232 spks): **2,400 steps** (13.27 epochs) for the 16 Tiny/Small 1-D models (`margin_warmup_steps=300` on `ls_conformer_small_arcface` and `ls_conformer_small_cosface`) and **2,600 steps** (14.37 epochs) for the 3 Base / 2-D ResNet models.
  - **CN-Celeb2** (4 models; 2,909 utts / 119 spks): **1,600 steps** (17.60 epochs) for the 3 Conformer metric-learning models and **1,800 steps** (19.80 epochs; `margin_warmup_steps=250`) for `cn_ecapa_tdnn_small_arcface`.
  - **VoxCeleb1** (2 models; 750 utts / 30 spks): **1,000 steps** (42.67 epochs).
- **Uniform variable-length crop provenance**: all 44 models were trained from scratch at `HEAD` with `variable_length_training: true` ($\mathcal{U}(90, 180)$ frames with exact padding masks) and seeded RNGs. Step-0 loss fingerprinting (`scripts/fingerprint_released_checkpoints.py` → `pretrained_models/step0_fingerprints.json`, `scripts/write_training_provenance.py`) confirms 42 `variable` matches and 2 `both` matches (0 `fixed`, 0 `neither`).
- **Converged benchmark highlights** (`pretrained_models/benchmark_results.json`, `pretrained_models/vox1_o_10spk_subset_results.json`):
  - **Pooled 1-utt EER across all 44 models drops to 14.60–22.35%** (`14.60–19.25%` across the 19 `univ_*` models; `19.15–29.96%` on the 10-speaker, 2,500-trial VoxCeleb1-O subset), improving over the 400-step v0.3.0 zoo (`18.75–30.23%`) on every model.
  - **Angular-margin classification overtakes metric learning at convergence**: `univ_conformer_small_arcface` (**14.60%** Pooled 1-utt / **10.87%** 3-utt / **14.63%** Macro 1-utt), `univ_conformer_small_sphereface` (**14.60%** / **10.53%**), and `univ_conformer_small_cosface` (**14.71%** / **10.40%** Pooled 3-utt / **9.63%** Macro 3-utt / **19.15%** VoxCeleb1-O subset) lead the 44-model zoo, whereas under the 400-step v0.3.0 budget they lagged `ge2e` (`22.41–25.33%` vs `19.40%`). On LibriSpeech, `ls_conformer_small_cosface` and `ls_conformer_small_arcface` reach **5.17%** (`2.50%` 3-utt) and **5.23%** (`2.20%` 3-utt).
  - **2-D ResNet-18 and capacity scaling inversions resolved**: `univ_resnet_small_ge2e` improves from `27.89%` (400 steps) to **15.60%** Pooled 1-utt (`16.06%` Macro, second among the 6 universal Small backbones behind `univ_lstm_small_ge2e` at `15.50%`), and LibriSpeech Conformer scaling orders monotonically (`base` `7.40%` < `small` `7.77%` < `tiny` `7.87%`).
  - **Universal multi-domain training beats single-domain specialists across all 19/19 matched pairs** on Pooled 1-utt, Macro 1-utt, and Pooled 3-utt EER.
- **Re-exported FP32 & INT8 TFLite models** (`scripts/export_model.py`, `scripts/eval_tflite_models.py`): all 12 TFLite binaries across 6 repositories were re-exported from the converged checkpoints (`3.44–3.61x` compression to `1.90–2.33 MB`; `|INT8 - FP32|` EER delta $\le$ **0.10 pp**; mean FP32/INT8 embedding cosine similarity `0.999935–0.999972`).

### Converged Ablations & Statistical Controls
- **R1 ablations at 4,600 / 2,400 steps** (`scripts/run_r1_ablations.py` → `pretrained_models/ablation_results.json`): (1) pure within-domain batching (`p_within=1.0`, **15.00%** Pooled 1-utt) outperforms hybrid `0.75` (`15.81%`) and cross-domain `0.0` (`16.51%`) once converged because same-domain impostors provide harder within-channel negatives; (2) blended BXS (`15.62%`) and paper-faithful Dr-Vectors (`15.47%`) outperform pure extended-set softmax (`16.44%`); (3) variable-length $\mathcal{U}(90, 180)$ training reduces short 1.0 s utterance EER by **1.06 pp** (`20.69%` vs `21.75%` for fixed `T=180`); (4) bidirectional Mamba reaches **15.59%** Pooled 1-utt vs `16.56%` unidirectional on Universal (`8.60%` vs `8.87%` on LibriSpeech).
- **R2 multi-seed stability, dedicated horizon schedules & matched-data controls** (`scripts/run_r2_controls.py` → `pretrained_models/r2_seed_and_control_results.json`): 3-seed Pooled 1-utt standard deviations shrink from `~0.73%` (at 400 steps) to **0.08%** (`univ_conformer_small_ge2e`: `15.13 ± 0.08%`), **0.14%** (`univ_ecapa_tdnn_small_ge2e`: `16.58 ± 0.14%`), and **0.41%** (`ls_conformer_small_ge2e`: `20.16 ± 0.41%`). Dedicated cosine schedules improve Pooled 1-utt EER monotonically from `20.79%` (400 steps) to `19.21%` (800), `18.39%` (1,200), `16.88%` (2,400), and `15.81%` (4,600). Subsampling Universal to **5,788 utterances across 381 speakers** achieves **17.04%** at 2,400 steps (beating `ls_conformer_small_ge2e` `20.79%` by **3.75 pp** at identical utterances and compute) and **15.28%** at 4,600 steps, isolating multi-domain speaker diversity as the primary driver of cross-domain generalization.
- **Model cards, Hub uploads, Gradio demo & documentation**: regenerated all 44 `pretrained_models/<id>/README.md` cards (`flaxspeaker/model_card.py`, `scripts/update_hf_model_cards.py --include_weights`), updated `hf_space/`, regenerated figures (`scripts/generate_figures.py`) and tables (`scripts/generate_report_tables.py`, `scripts/generate_paper_tables.py`), and aligned `README.md`, `RESEARCH_REPORT.md`, and the companion LaTeX paper with `v0.4.0`.

## 0.3.0

First PyPI release that can load the released checkpoints. PyPI `0.2.0` corresponds to git tag `v0.2.0` (`526be70`, 2026-10-04), a snapshot taken *before* the 44 checkpoints, `load_pretrained`, `encode_features`, `FLAXSPEAKER_PRETRAINED_ROOT` and `model_card.py` existed; a `pip install flaxspeaker==0.2.0` cannot run the README quickstart or the model cards. The version number is now asserted consistent across `pyproject.toml`, `setup.py` and `flaxspeaker.__version__` (`tests.py::test_version_consistency`); the proposed CI workflow (`ci/python-app.proposed.yml`, see Fixes) builds the wheel and imports it from a clean virtualenv.

### Training-crop provenance of the released zoo (correction)
- **The released checkpoints, except the two `*_ge2e_contrast` models, were trained with fixed 180-frame crops and all-ones masks**, not with the `T ~ U(90, 180)` variable-length crops stated in the README, `RESEARCH_REPORT.md`, the paper, all 44 YAMLs and all 44 `config.json` files. Cause: in the working tree that produced them (before `1cb90c7`), `get_batched_nm_input` / `get_batched_classification_input` defaulted to `variable_length=False` and `run_research_benchmarks.py` did not pass the flag, although it set `variable_length_training = True` on the serialized config. `9accf95` made the driver honour the flag; only the two `*_ge2e_contrast` checkpoints were retrained after that.
- **Evidence** (`scripts/fingerprint_released_checkpoints.py` → `pretrained_models/step0_fingerprints.json`): for each of the 44 checkpoints, one training step at the released seed from the released YAML reproduces the archived `initial_loss` to 4 decimals only under fixed crops for 34 checkpoints (e.g. `univ_conformer_small_ge2e` 1.9180 fixed vs 2.0525 variable; `ls_conformer_small_ge2e` 2.0965 vs 2.1204), within 7e-4 for the 5 `*_pfas*` checkpoints (post-release PFAS scorer numerics), under variable-length crops for `ls_conformer_small_ge2e_contrast` (1.0005 vs 1.0000), is not discriminable for 2 (`univ_conformer_small_ge2e_contrast`, `univ_ecapa_tdnn_tiny_ge2e`; assigned from the git history), and cannot be established for the 2 `*_triplet` checkpoints (unseeded triplet sampler at the time). The two `*_sphereface` checkpoints match only with the constant annealing λ = 5 that `sphereface_loss` used before `9accf95`.
- **Consequences fixed in this release**: the 40 affected `configs/*.yml` and `config.json` files now say `variable_length_training: false`; every `config.json` carries a `training_provenance` block (`scripts/write_training_provenance.py`; round-tripped by `FlaxSpeakerConfig`); the 44 model cards derive their provenance paragraph from it (no more date-based reasoning); Study 3 of the ablations is relabelled (its "variable-length" row was the fixed-crop released checkpoint) and now contains the genuine same-code pair — fixed `T = 180` 18.99 % [18.14, 19.82] vs `U(90,180)` 20.94 % [20.02, 21.71] pooled 1-utt EER (seed 42, `HEAD`); the explanation "earlier revisions / modules changed afterwards" in the README, report, model cards and paper is replaced by the fingerprint. Re-training `univ_conformer_small_ge2e` seed 42 with fixed crops lands inside the released CI (18.99 % vs 19.40 % [18.61, 20.26]); for `ls_conformer_small_ge2e` the fixed-crop re-run gives 21.15 % [20.41, 22.12] vs the released 20.12 % [19.30, 21.04] (overlapping CIs; the residual post-step-0 difference is not explained).
- **New fixed-crop controls** (`scripts/run_r3_fixed_crop_controls.py` → `pretrained_models/r3_fixed_crop_controls.json`, 6 runs): `p_within` = 0.0 / 1.0 at fixed crops (20.55 % / 19.84 % pooled 1-utt vs 18.99 % for 0.75), a 3-seed fixed-crop floor (18.73 / 19.85 / 20.16 → 19.58 ± 0.76 %, vs 20.64 ± 0.73 % with variable-length crops), and the `ls_conformer_small_ge2e` seed-42 fixed-crop re-run. The former "main robust finding" that stratified batching helps with non-overlapping CIs compared two crop regimes and two code revisions and is withdrawn; at fixed crops the hybrid-vs-cross-domain gap is ≈ 2 seed sd (CIs barely overlap) and the hybrid-vs-within-domain gap ≈ 1 sd.

## Unreleased (Round 2 review revisions, after v0.2.0)

### Correctness fixes
- **Bidirectional LSTM** (`LstmBackbone`): the backward `nn.RNN` was built without `seq_lengths` (padding leaked into every valid frame; max abs diff 4.71 in the reviewer's check) and without `keep_order=True` (its outputs were time-reversed relative to the forward direction before concatenation). Both fixed; padding invariance is now exact (0.0) and covered by `tests.py`. **No released checkpoint was affected**: none of the 44 configs sets `lstm.bidirectional: true`.
- **AS-Norm**: `evaluate_verification_trials` / `evaluate_multi_enroll_trials` no longer use the evaluation set itself as the impostor cohort. A `cohort_embeddings` array disjoint from the trial utterances is now required (`require_disjoint_cohort` raises otherwise). No reported number used AS-Norm.
- **`min_learning_rate`** is honoured exactly by `build_optimizer` (previously floored at `0.01 * lr`). All benchmark YAMLs now set it to the value that was actually used (`1.5e-5`, `1.2e-5` for `base`).
- **Export window**: `export.sequence_length == 100` was a magic "unset" sentinel; any positive value is now honoured and `0` means `model.seq_len`. All 44 configs declare `180`, the window the released `.tflite` files were traced with (verified `[1, 180, 80]` for all 12 files).

- `dataset.get_triplet` accepts an explicit `random.Random` for reproducibility.
