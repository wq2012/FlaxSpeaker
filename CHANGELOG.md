# Changelog

## 0.3.0

First PyPI release that can load the released checkpoints. PyPI `0.2.0` corresponds to git tag `v0.2.0` (`526be70`, 2026-10-04), a snapshot taken *before* the 44 checkpoints, `load_pretrained`, `encode_features`, `FLAXSPEAKER_PRETRAINED_ROOT` and `model_card.py` existed; a `pip install flaxspeaker==0.2.0` cannot run the README quickstart or the model cards. The version number is now asserted consistent across `pyproject.toml`, `setup.py` and `flaxspeaker.__version__` (`tests.py::test_version_consistency`); the proposed CI workflow (`ci/python-app.proposed.yml`, see Fixes) builds the wheel and imports it from a clean virtualenv.

### Training-crop provenance of the released zoo (correction)
- **The released checkpoints, except the two `*_ge2e_contrast` models, were trained with fixed 180-frame crops and all-ones masks**, not with the `T ~ U(90, 180)` variable-length crops stated in the README, `RESEARCH_REPORT.md`, the paper, all 44 YAMLs and all 44 `config.json` files. Cause: in the working tree that produced them (before `1cb90c7`), `get_batched_nm_input` / `get_batched_classification_input` defaulted to `variable_length=False` and `run_research_benchmarks.py` did not pass the flag, although it set `variable_length_training = True` on the serialized config. `9accf95` made the driver honour the flag; only the two `*_ge2e_contrast` checkpoints were retrained after that.
- **Evidence** (`scripts/fingerprint_released_checkpoints.py` → `pretrained_models/step0_fingerprints.json`): for each of the 44 checkpoints, one training step at the released seed from the released YAML reproduces the archived `initial_loss` to 4 decimals only under fixed crops for 34 checkpoints (e.g. `univ_conformer_small_ge2e` 1.9180 fixed vs 2.0525 variable; `ls_conformer_small_ge2e` 2.0965 vs 2.1204), within 7e-4 for the 5 `*_pfas*` checkpoints (post-release PFAS scorer numerics), under variable-length crops for `ls_conformer_small_ge2e_contrast` (1.0005 vs 1.0000), is not discriminable for 2 (`univ_conformer_small_ge2e_contrast`, `univ_ecapa_tdnn_tiny_ge2e`; assigned from the git history), and cannot be established for the 2 `*_triplet` checkpoints (unseeded triplet sampler at the time). The two `*_sphereface` checkpoints match only with the constant annealing λ = 5 that `sphereface_loss` used before `9accf95`.
- **Consequences fixed in this release**: the 40 affected `configs/*.yml` and `config.json` files now say `variable_length_training: false`; every `config.json` carries a `training_provenance` block (`scripts/write_training_provenance.py`; round-tripped by `FlaxSpeakerConfig`); the 44 model cards derive their provenance paragraph from it (no more date-based reasoning); Study 3 of the ablations is relabelled (its "variable-length" row was the fixed-crop released checkpoint) and now contains the genuine same-code pair — fixed `T = 180` 18.99 % [18.14, 19.82] vs `U(90,180)` 20.94 % [20.02, 21.71] pooled 1-utt EER (seed 42, `HEAD`); the explanation "earlier revisions / modules changed afterwards" in the README, report, model cards and paper is replaced by the fingerprint. Re-training `univ_conformer_small_ge2e` seed 42 with fixed crops lands inside the released CI (18.99 % vs 19.40 % [18.61, 20.26]); for `ls_conformer_small_ge2e` the fixed-crop re-run gives 21.15 % [20.41, 22.12] vs the released 20.12 % [19.30, 21.04] (overlapping CIs; the residual post-step-0 difference is not explained).
- **New fixed-crop controls** (`scripts/run_r3_fixed_crop_controls.py` → `pretrained_models/r3_fixed_crop_controls.json`, 6 runs): `p_within` = 0.0 / 1.0 at fixed crops (20.55 % / 19.84 % pooled 1-utt vs 18.99 % for 0.75), a 3-seed fixed-crop floor (18.73 / 19.85 / 20.16 → 19.58 ± 0.76 %, vs 20.64 ± 0.73 % with variable-length crops), and the `ls_conformer_small_ge2e` seed-42 fixed-crop re-run. The former "main robust finding" that stratified batching helps with non-overlapping CIs compared two crop regimes and two code revisions and is withdrawn; at fixed crops the hybrid-vs-cross-domain gap is ≈ 2 seed sd (CIs barely overlap) and the hybrid-vs-within-domain gap ≈ 1 sd.

### Fixes
- `scripts/eval_tflite_models.py`: per-domain TFLite EERs now carry stratified-bootstrap 95 % CIs (`eer_ci95_low` / `eer_ci95_high`; `tflite_eval.eer_ci95_fp32` / `eer_ci95_int8` for the primary set); features are extracted with each model's own frontend / VAD config instead of library defaults; the `benchmark_results.json["tflite_exports"]` write-back matched a key that never existed (`<id>` instead of `<id>_fp32` / `_int8`), so the export-time single-call `latency_ms` (e.g. `univ_lstm_small_ge2e_int8` 85.986 ms > fp32 52.055 ms) was never overwritten — it is now replaced by the 50-run mean (docstring said 100 invocations; it is 50).
- Gradio demo (`hf_space/app.py`): with two or three enrollment utterances the verdict used the 1-utt EER operating point; it now uses the checkpoint's pooled 3-utt operating point (`domains_3utt.universal_pooled.eer_threshold`; `model_eer_operating_points` exposes both), with a checkbox to fall back to the manual slider. The PFAS 3-enrollment scoring kernel is warmed at load (previously only 1- and 2-enrollment, so the first 3-utt PFAS call paid a compile). The demo exposes the same two VAD knobs as the CLI (`vad_snr_margin_db`, `vad_top_db`).
- `scripts/inference.py`: `--vad_snr_margin_db` added; with `--tflite_path` the default threshold is the TFLite export's own `tflite_eval.domains_1utt_<fp32|int8>.universal_pooled.eer_threshold` (previously the full-sequence JAX threshold); multi-utterance enrollment uses the 3-utt operating point; the private `_resolve_frontend` is no longer called (public `FlaxSpeakerModel.resolve_frontend`).
- `FlaxSpeakerModel.eer_threshold(domain, num_enroll=...)`, `resolve_frontend(...)`, `load_exp_config(dir)`; `FlaxSpeakerConfig.training_provenance`.
- `FeatureCache`: the on-disk signature (`v3`) now hashes every frontend / VAD field that affects the features (`sample_rate`, `frame_size_ms`, `frame_step_ms`, `n_fft`, `fmin`, `fmax`, `preemph`, `log_offset`, `cmvn_norm_vars`, `n_mfcc`; VAD `adaptive_percentile`, `snr_margin_db`, `spectral_flatness_threshold`, `min_speech_frames`); legacy `v2` files are still found but only when all omitted fields are at their defaults; the in-memory dictionary is bounded; `FeatureCache.merged(...)` replaces the `_cache.update` pokes in the benchmark / ablation / control scripts.
- `vad.VadProcessor` no longer mutates the caller's `VadConfig`; the NN-resampled mask alignment and the fact that `spectral` mode is a *union* with the energy mask are documented.
- README: two script names that never existed in the repository (`publish_to_hf` and `prepare_hf_demo_audio` under `scripts/`) are removed and the real Hub publishing path is described; `tests.py::test_readme_script_references_exist` guards every `scripts/*.py` mentioned in README / RESEARCH_REPORT / CHANGELOG.
- Tests that need released weights skip when neither local `model.safetensors` nor Hub access is available (`HF_HUB_OFFLINE=1`).
- Packaging: single dependency list with lower bounds in `pyproject.toml` (`setup.py` is a shim); `run_tests.sh` no longer references a fixed `/tmp` virtualenv. The updated CI workflow (`actions/checkout@v4` / `setup-python@v5`, wheel build + clean-virtualenv import smoke test) is staged as `ci/python-app.proposed.yml`: the release was pushed with a token without the `workflow` scope, which GitHub requires for changes under `.github/workflows/`; copy it over `.github/workflows/python-app.yml` from a session with that scope. `transformers` remains a core dependency because `FlaxSpeakerConfig` subclasses `transformers.PretrainedConfig`.

## Unreleased (Round 3 reviewer verification of the Round 2 revision)

### Findings
- **Released checkpoints are not re-trainable from the current code** (superseded by the 0.3.0 provenance correction above: they *are* re-trainable to within the seed floor once the crop regime is matched). Re-training seed 42 through `scripts/run_r2_controls.py --seeds 42` gives 20.94 % / 21.40 % pooled 1-utt EER for `univ_` / `ls_conformer_small_ge2e` (archived released values: 19.40 % / 20.12 %); the first-step loss already differs (2.0525 vs 1.9180; 2.1204 vs 2.0965). Re-*evaluating* the released weights with the current code (`scripts/evaluate.py --data_root ...`) reproduces their archived per-domain EERs exactly. Both checks are archived under `seed42_rerun_current_code` and `released_checkpoint_reeval_current_code` in `pretrained_models/r2_seed_and_control_results.json`; the Round-2 claim that the released checkpoints were a lucky draw from the *same* seed distribution is withdrawn in the README, `RESEARCH_REPORT.md` and the paper.
- End-to-end CLI check (not run in Round 2): `scripts/train.py` from a regenerated YAML and from all five `--preset`s (incl. the Conformer `subsample_factor=2` ATP preset and the PFAS `atp_ffn` preset), `scripts/evaluate.py`, `scripts/export_model.py --export_tflite` and `scripts/inference.py` all run on a 10-speaker smoke set.

### Fixes
- **Demo latency claim**: `hf_space/app.py` embedded utterances with `evaluation.run_inference`, which re-traces an XLA kernel for every distinct utterance length, so the "steady-state latency" telemetry was wrong for every new clip length (1.4-2.7 s first-call latencies measured). The demo now uses the new `evaluation.encode_features` (the benchmark's masked fixed-window path, `prepare_eval_input`), so one warm-up compiles the kernel used for all inputs; a test asserts `encode_features == run_inference` to 1e-4 on all three length branches.
- `scripts/inference.py` used a hard-coded 0.55 threshold for every model and scorer; it now defaults to the checkpoint's own pooled 1-utt EER operating point via the new `FlaxSpeakerModel.eer_threshold()` (`eval_results.json` is loaded by `from_pretrained`), and reports `threshold_source`.
- Documentation: the universal-vs-specialist win/loss lists in README and the paper were hand-typed and wrong (omitted the LSTM loss and the Transformer / ECAPA-base / contrast wins); they are now generated from the archive. "19-32 % EER" is replaced by the archive's 18.75-30.23 % pooled 1-utt range (22.5-32.2 % on the Vox1-O subset). The paper's "ArcFace loss 9.9 vs ~11.9 at chance" (a number in no archive) is replaced by the archived initial/final losses.

## Unreleased (Round 2 review revisions, after v0.2.0)

### Correctness fixes
- **Bidirectional LSTM** (`LstmBackbone`): the backward `nn.RNN` was built without `seq_lengths` (padding leaked into every valid frame; max abs diff 4.71 in the reviewer's check) and without `keep_order=True` (its outputs were time-reversed relative to the forward direction before concatenation). Both fixed; padding invariance is now exact (0.0) and covered by `tests.py`. **No released checkpoint was affected**: none of the 44 configs sets `lstm.bidirectional: true`.
- **AS-Norm**: `evaluate_verification_trials` / `evaluate_multi_enroll_trials` no longer use the evaluation set itself as the impostor cohort. A `cohort_embeddings` array disjoint from the trial utterances is now required (`require_disjoint_cohort` raises otherwise). No reported number used AS-Norm.
- **`min_learning_rate`** is honoured exactly by `build_optimizer` (previously floored at `0.01 * lr`). All benchmark YAMLs now set it to the value that was actually used (`1.5e-5`, `1.2e-5` for `base`).
- **Export window**: `export.sequence_length == 100` was a magic "unset" sentinel; any positive value is now honoured and `0` means `model.seq_len`. All 44 configs declare `180`, the window the released `.tflite` files were traced with (verified `[1, 180, 80]` for all 12 files).
- **Feature-noise SNR**: the hidden clamp `snr_min_db -> max(12, .)` is removed; configs now state `12.0` explicitly.
- **One VAD constant**: `prepare_datasets.py` and the VoxCeleb1-O-subset evaluation used `energy_db_threshold=30` while training used the 26 dB default. All scripts now use `VadConfig()` (26 dB); the subset results were regenerated for all 44 models (`pretrained_models/vox1_o_10spk_subset_results.json`).
- `dataset.get_triplet` accepts an explicit `random.Random` for reproducibility.

### Configuration hygiene
- Unknown config keys now raise `ValueError`; 30 never-consumed fields were removed (listed in `configs._DEPRECATED_CONFIG_KEYS`; still accepted with a `DeprecationWarning` so pre-Round-2 `config.json` files load).
- Conformer `layer_order` and `subsample_factor` (stack-by-N after `subsample_after_layer` blocks, with mask subsampling) are now implemented; `odyssey2022_conformer_atp_config(pure_paper_mode=True)` builds a different module than the default (tested).
- Hidden `ge2e_contrast` overrides (`init_b -5 -> -1`, `b` gradient scale 0.5) and the surrogate gradient are now explicit config fields (`ge2e_contrast_surrogate`, `ge2e_contrast_b_grad_scale`); the default is the pure Eq. 7 gradient. `ge2e_contrast` + `pfas` scoring is rejected.
- `scripts/migrate_configs_r2.py` rewrote all 44 YAMLs and `config.json` files accordingly.

### Paper-faithful presets and honest naming
- `interspeech2021_dr_vectors_config(pure_paper_mode=True)`: 200/56 base/side split (`cosine_dims`), 3 x 256 leaky-ReLU(0.2) without LayerNorm, weighted-sum read-out, trainable affine, pure extended-set softmax; the 3-term cosine expansion is labelled a FlaxSpeaker extension.
- `odyssey2022_pfas_config(pure_paper_mode=True)`: `atp_ffn` head (single-head linear-sigmoid ATP, no LayerNorm), 32 tied keys x (16 + 48), pure extended-set softmax. The released `shared_nonlinear` + global-anchor head is named **PFAS-SN** (FlaxSpeaker extension).
- `icassp2018_ge2e_config(pure_paper_mode=True)`: 3 x LSTM-768 + 256 projection, last-frame pooling, linear output.
- Citations fixed: Dr-Vectors "Eq. 3/7" -> Eq. 2 (the paper has two equations); PFAS "Eqs. 5-6" -> Eqs. 5-7; the ATP paper is cited as a language-identification paper; Conformer -> Gulati et al.
- README gains a "Deviations from the source papers" table; model cards are generated by the new `flaxspeaker/model_card.py` with variant labels, training-budget notice, Vox1-O-subset row, TFLite caveat, total-parameter wording and `pipeline_tag: feature-extraction`; the misleading Whisper `preprocessor_config.json` is no longer written and was deleted from the Hub repos.

### Benchmark artifacts
- `scripts/eval_vox1_o_subset.py` (renamed from `eval_voxceleb1_official.py`): protocol key `vox1_o_10spk_subset`, provenance fields, legacy keys removed.
- `scripts/run_r2_controls.py`: seed-noise floor (seeds 0/1/2 for `univ_` and `ls_conformer_small_ge2e`), honest 800-step horizon run, matched-data control -> `pretrained_models/r2_seed_and_control_results.json`.
- `scripts/generate_paper_tables.py` / `generate_report_tables.py`: every number in the paper and in `RESEARCH_REPORT.md` Section 10 is generated from the JSON archives.

### Demo
- Per-model default threshold (pooled 1-utt EER operating point from `eval_results.json`), scorer-dependent slider range, JIT warm-up with steady-state latency, self-contained `requirements.txt` (installs `flaxspeaker`), default model `univ_conformer_tiny_ge2e`, AS-Norm toggle removed; `scripts/deploy_hf_space.py` can deploy the demo to a Space of your own (the demo is not hosted under `wq2012`; see README).
